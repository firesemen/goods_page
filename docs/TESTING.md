# Проверка версии 0.1.0

Проведено 3 ноября 2026 года в облачной Linux-среде.

| Проверка | Результат |
|---|---|
| Ядро JVM: даты, високосный год, порядок доставки, расход, удаление, шифрование, копии | 140 проверок, пройдены |
| Worker API и SQL, Node.js 24 + настоящий SQLite | 6 тестов, пройдены |
| Сборка APK, Android SDK 35, AGP 8.9.2, Gradle 8.11.1 | Успешно |
| Android Lint | Нет ошибок и предупреждений |
| Android 12/API 31, программный x86_64 эмулятор Fridge31 | 1 интеграционный тест, 14 проверок, пройден; 0 ошибок, 0 пропусков |
| Обмен рядом: 2 независимых журнала, Android NSD и сокеты | 11 проверок, пройдены; 37 уникальных событий |
| Подпись APK | Проверена apksigner, v2 |

Android-проверки выполнялись через `:app:connectedDebugAndroidTest`. Проверены Keystore, шифрованные операции SQLite, даты и отмена открытия, слияние автономного расхода, отбрасывание повреждённого пакета, копия с паролем, реальная форма добавления, MediaStore/ImageDecoder и размер фото, карточка на экране, локальное уведомление, настоящий локальный сокет обмена и применение принятой операции.

Первая попытка Android smoke-теста остановилась на неверном утверждении теста: UUID продукта сравнивался с UUID операций. Исправлен тест, затем проверка пройдена через стандартный runner. После разделения локальной и сетевой очередей весь Android smoke-тест и lint повторно прошли на окончательной сборке.

Не проверялись: два физических телефона, mDNS через реальный домашний роутер, аппаратная камера, фоновые уведомления после перезапуска и при энергосбережении разных производителей, Android 13+ диалог разрешений на реальном устройстве, батарея, опубликованный Cloudflare Worker/D1, интернет-обмен из РФ. Код ретранслятора подготовлен, но сервис не развёрнут. Это тестовая APK, не опубликованный магазинный релиз.

Дальнейшая приёмка: [PHONE_CHECKLIST.md](PHONE_CHECKLIST.md).

## Дополнительная проверка обмена рядом

Использован отдельный `WifiInstrumentation`: два независимо идентифицированных журнала с разными UUID устройств и общим приглашением, плюс третий журнал другой семьи. Участники обнаруживают друг друга через настоящие Android NSD/mDNS API и подключаются через производственные сокеты `NearbySync`. Подставных сетевых ответов и вызова merge вместо сетевого обмена нет.

Подтверждены 11 условий: сходимость шифрованных журналов, передача продукта и данных фото в обе стороны через несколько порций, успешные статусы обоих участников, изоляция другой семьи, независимые изменения без соединения, корректный расход 3 − 1 − 1 = 1 после переподключения, срок после открытия, сохранение удаления при конкурентном переименовании, совпадение журналов, отсутствие повторного расхода при повторной доставке, сохранение изоляции после переподключения. Всего 37 уникальных операций.

Первый запуск дополнительной проверки через Gradle завершился сбоем установки (`package install-commit: Broken pipe`), до выполнения теста. После восстановления службы установщика обе APK установлены успешно, runner запущен через `adb shell am instrument -w -r ru.fridgedays.app.test/ru.fridgedays.app.WifiInstrumentation`. Зафиксированы начало теста, успешный статус, `checks=11`, `PASS` и код завершения `-1`.

Два участника работали внутри одного Android 12 эмулятора. Передача через физический Wi-Fi-роутер и два реальных телефона пока не подтверждена. В рабочем приложении используется прежнее хранилище `Store`; интерфейс `SyncReplica` позволяет проверять транспорт двумя отдельными журналами без изменения личных данных установленного приложения.
