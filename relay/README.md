# Необязательный зашифрованный ретранслятор

Этот код не развёрнут. Для локального холодильника он не нужен. Для передачи между телефонами в разных сетях нужен общий доступный экземпляр API. Клиент хранит данные и без него.

## Развёртывание вручную через Cloudflare Dashboard

1. В аккаунте на **Workers Free** создать D1-базу `fridge-days`. Не подключать Paid или R2: они не нужны этому примеру.
2. В консоли D1 выполнить `schema.sql` из этой папки.
3. Создать Worker с модульным JavaScript-кодом `src/worker.js`.
4. Добавить D1 binding **DB**, связанный с созданной базой.
5. В приложении открыть **Семья → Параметры регистрации ретранслятора**. Скопировать JSON вида `{"UUID_СЕМЬИ_UUID_ХОЛОДИЛЬНИКА":"ХЕШ"}` и задать его целиком как переменную **ROOMS** Worker. Это хеш отдельного токена, не ключ расшифровки. Значение `{}` закрывает доступ всем семьям.
6. При готовности самостоятельно опубликовать Worker. Его HTTPS-origin без пути, например адрес вида `https://ИМЯ.ПОДДОМЕН.workers.dev`, указать на первом телефоне в **Семья → HTTPS-адрес ретранслятора**.
7. Передать второму телефону обновлённое приглашение: в нём появится адрес. Принятие приглашения той же семьи сохраняет её данные. Либо указать адрес вручную на обоих телефонах.
8. Нажать **Синхронизировать сейчас** и дождаться успешного статуса. Добавить продукт на одном телефоне и проверить появление на другом **при разных сетях**. Отдельно проверить домашнего и мобильного оператора в РФ; доступность Cloudflare здесь не подтверждена.

Для CLI есть `wrangler.jsonc`: заполнить `database_id` и `vars.ROOMS`, затем применить `schema.sql` и развёрнуть обычными средствами Wrangler. Сам код Worker не содержит аккаунтных ключей; токены провайдера не должны попадать в проект, APK или чат.

## Поведение

Сервер принимает только заранее зарегистрированные пространства. Проверяет SHA-256 bearer-capability; не имеет AES-ключа семьи. Хранит неизменяемые зашифрованные события и отдаёт их по курсору. Повтор события не добавляет дубликат, другое содержимое с тем же ID отклоняется. Тела ограничены 1 МБ, не более 20 событий за запрос, история клиента — 20 000 операций. Имена, даты, количество и фото серверу не раскрываются; идентификаторы, размеры и сетевые метаданные видны провайдеру.

Активное приложение проверяет облако каждую минуту; JobScheduler просит фоновую проверку с периодом 15 минут. Android может отложить её. Для немедленного обмена есть кнопка. Полностью выключенный/принудительно остановленный телефон не получает обновления до возобновления работы.

`npm test` использует Node.js 22.13+ и SQLite, не требует Cloudflare-аккаунта и не обращается в сеть. Эти тесты проверяют API/SQL, но не доказывают доступность развёрнутого D1 или провайдера из РФ.

Подтверждённые лимиты бесплатного тарифа и первоисточники перечислены в [исследовании](../docs/RESEARCH.md). При превышении лимитов бесплатного плана облачный обмен может остановиться; локальный учёт и обмен рядом продолжают работать.
