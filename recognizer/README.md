# Установка распознавания через сайт Cloudflare

Это отдельный Worker для кнопки **«Отправить фото в облако»** в APK 0.3.0+. Установка через браузер: терминал, Wrangler, API-токены и покупка сервера не нужны. Локальное распознавание уже работает без этого Worker.

Worker использует Workers AI для чтения фотографий и D1 только для счётчика запросов. Адрес и разрешение распознавания настраиваются отдельно от обмена запасами. Один Worker можно использовать для нескольких семей, добавив их параметры в `ROOMS`.

## 1. Сначала получить параметры в приложении

1. Установите APK 0.3.0 поверх текущей версии на оба телефона.
2. Проверьте, что оба уже подключены к одной семье. Их приглашение должно быть общим.
3. Откройте **шестерёнку → Распознавание по фото → Параметры ROOMS для распознавания → Копировать**.
4. Сохраните скопированное значение для шага 4. Оно выглядит так:

```json
{"UUID_СЕМЬИ_UUID_ХОЛОДИЛЬНИКА":"64_шестнадцатеричных_символа"}
```

Это только пример формы, а не рабочее значение. Вставляйте всю строку JSON из приложения, с фигурными скобками и кавычками. Используйте именно экран **распознавания**. Кнопка регистрации ретранслятора в разделе «Семья» выдаёт другое разрешение.

Ни пароль Cloudflare, ни приглашение с ключом семьи в Worker вставлять не нужно. В `ROOMS` находится хеш отдельного разрешения; сам ключ расшифровки запасов серверу и модели не отправляется.

## 2. Создать D1 для лимита запросов

1. Откройте [dash.cloudflare.com](https://dash.cloudflare.com/) и выберите свой аккаунт.
2. В меню аккаунта откройте **Storage & databases → D1 SQL Database**. В некоторых версиях интерфейса раздел называется просто **D1**; можно найти его поиском панели.
3. **Create database → Dashboard**. Название: `fridge-photo-usage`. Создайте базу.
4. Откройте базу → **Console** и выполните SQL из [schema.sql](schema.sql), целиком:

```sql
CREATE TABLE IF NOT EXISTS recognition_usage (
  room TEXT NOT NULL,
  day TEXT NOT NULL,
  count INTEGER NOT NULL,
  PRIMARY KEY(room,day)
);
```

5. Нажмите **Execute / Run**. Таблица пустая; это нормально. Фотографии и распознанный текст в D1 не записываются.

## 3. Создать Worker и вставить код

1. Откройте **Workers & Pages → Create application → Create Worker**. В новом меню этот раздел может находиться в **Compute & AI**.
2. Выберите **Start with Hello World**, задайте свободное имя, например `fridge-photo-yourname`, и нажмите **Deploy**.
3. Откройте созданный Worker → **Edit code**.
4. Откройте [worker.js](worker.js) в этом репозитории и нажмите **Raw**. Скопируйте весь файл, начиная с комментария и заканчивая последним `};`.
5. Полностью замените содержимое основного `worker.js` в редакторе Cloudflare. Это обычный JavaScript Worker с `export default`; дополнительные файлы и npm-пакеты ему не нужны.
6. Нажмите **Deploy**. До добавления привязок распознавание ещё не готово.

Загрузка кода в ваш аккаунт происходит только когда вы сами нажимаете Deploy. Из среды разработки ничего в Cloudflare не публиковалось.

## 4. Добавить две привязки и переменные

Вернитесь на страницу Worker. Вкладка **Bindings**, либо **Settings → Bindings**:

| Тип привязки | Variable name | Что выбрать |
|---|---|---|
| Workers AI | `AI` | Подключить Workers AI своего аккаунта |
| D1 database | `DB` | Созданную базу `fridge-photo-usage` |

Регистр важен: именно `AI` и `DB`. Для Workers AI панель может попросить принять условия сервиса — прочитайте их и подключите, если они вам подходят.

Затем откройте **Settings → Variables and Secrets** (или **Variables → Add**):

| Имя | Тип | Значение |
|---|---|---|
| `ROOMS` | Secret | Вся строка JSON, скопированная из настроек распознавания на телефоне |
| `DAILY_LIMIT` | Text | `20` |

Нажмите **Save / Deploy**, если панель предлагает применить изменения. `ROOMS` добавляется как один секрет, а не как отдельные переменные для каждого UUID. Модель уже выбрана в коде: `@cf/google/gemma-3-12b-it`; свой API-ключ модели не требуется, используется привязка `AI`.

Лимит — 20 **попыток** на семью/холодильник за сутки UTC. Неуспешный запрос к модели тоже расходует попытку. Для первого теста можно поставить `5`; разрешены значения от 1 до 100. Несколько одновременных запросов не обходят лимит. Остаток счётчика не является финансовой гарантией: стоимость одной попытки зависит от модели и снимков.

Для семейного пилота оставьте аккаунт на **Workers Free** и не подключайте автоматическую платную обработку. Workers AI имеет отдельную бесплатную суточную квоту в Neurons; D1 и Workers тоже имеют лимиты. Если бесплатная квота исчерпалась, приложение покажет ошибку и сохранит возможность локального распознавания. Актуальные условия: [Workers AI pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/), [D1 pricing](https://developers.cloudflare.com/d1/platform/pricing/). Если Cloudflare требует перейти на платный план для выбранной модели, сначала остановитесь и оцените условия — оплачивать сервис для работы приложения не обязательно.

## 5. Вписать адрес на обоих телефонах

1. На странице Worker скопируйте Production URL, например `https://fridge-photo-yourname.yoursubdomain.workers.dev`.
2. На каждом телефоне откройте **шестерёнку → Распознавание по фото**.
3. Вставьте адрес в **HTTPS-адрес Worker распознавания** и нажмите **Сохранить адрес распознавания**.
4. Вставляйте только начало адреса, без `/v1/...`, без параметров и без токенов. Завершающий `/` допускается.

Общий аккаунт Cloudflare на телефонах не нужен. Адрес хранится в настройках каждого телефона, а право доступа вычисляется из уже имеющегося приглашения семьи.

## 6. Проверить один продукт

1. Добавьте новую упаковку. Сфотографируйте название и массу/объём либо выберите фото.
2. При необходимости добавьте **«Снять срок крупно»** или **«Выбрать снимок срока»**. Второй снимок не заменит основное фото карточки.
3. **«Распознать на телефоне»** проверяет локальный сценарий, интернет не нужен.
4. Нажмите **«Отправить фото в облако»**, прочитайте подтверждение и нажмите **«Отправить»**. Только после этого выбранные снимки уйдут модели.
5. На экране **«Проверьте маркировку»** сравните поля с упаковкой. Каждую дату нужно отметить вручную. Дате без назначения выберите «Годен до» либо «Дата изготовления», только если это понятно из надписи.
6. **«Перенести в форму»** заполняет редактируемые поля. Затем **«Сохранить упаковку»** сохраняет обычную зашифрованную карточку; далее она обменивается по уже работающему Wi-Fi.

Открытие корневого URL в браузере может вернуть `{"error":"not_found"}`: это ожидаемо, у Worker нет веб-страницы. Проверяйте обработку кнопкой приложения. Не отправляйте снимок много раз подряд: автоматических повторов нет, каждый отдельный запрос расходует квоту.

## Если не получилось

| Сообщение | Что проверить |
|---|---|
| Worker не разрешил доступ, HTTP 401 | `ROOMS` скопирован из **распознавания**, а не из раздела обмена; оба телефона в той же семье; JSON вставлен целиком |
| Worker не настроен, HTTP 503 | Привязки называются `AI` и `DB`, база выбрана, `ROOMS` — корректный JSON, `DAILY_LIMIT` от 1 до 100 |
| HTTP 502 | Доступна ли модель в вашем аккаунте, не закончилась ли бесплатная квота; разрешён ли Workers AI. Посмотрите ошибки настройки в панели, не включайте логирование фотографий |
| HTTP 429 | Достигнут ваш дневной лимит. Попробуйте на телефоне или на следующий день UTC |
| Тайм-аут / нет соединения | Открывается ли домен Worker из вашей сети. Доступность Cloudflare в РФ зависит от оператора; другой Wi-Fi/мобильная сеть помогут определить причину |
| Облако работает, дата не найдена | Снимите саму маркировку крупно, ровно, без бликов. Нечитаемый срок заполните вручную |
| Один телефон работает, второй — нет | Проверьте одинаковый адрес Worker и общее приглашение семьи; адрес настраивается отдельно на каждом телефоне |

Нельзя решить сетевую недоступность сменой даты или отключением проверки TLS; приложение сохраняет проверку HTTPS-сертификатов. При недоступном Cloudflare остаются локальный OCR и обмен по домашнему Wi-Fi.

## Приватность и границы проверки

Фото передаётся по HTTPS, но модель Cloudflare получает его в читаемом виде. Это отличается от сквозного шифрования журнала запасов. Сам код Worker не пишет фото/текст в D1 и не вызывает `console.log`; хранится только счётчик по UUID и дню. Не включайте захват тел запросов в журналах. Правила обработки и технические журналы провайдера определяются Cloudflare: [Workers AI data usage](https://developers.cloudflare.com/workers-ai/platform/data-usage/). Отсутствие нашей базы фотографий не означает отсутствия инфраструктурных журналов у провайдера.

В репозитории проверены контракт Worker с тестовой подменой AI и настоящий SQL-счётчик. Публикация в вашем аккаунте, реальный ответ Gemma и доступность с ваших телефонов ещё требуют проверки по шагу 6. Точность на реальных упаковках не заявляется. Для первого пилота полезны 20–30 разных упаковок, включая точечную печать и блики.

Чтобы отключить облако, очистите адрес распознавания на обоих телефонах. Для отзыва серверного доступа удалите запись семьи из `ROOMS`. Это не влияет на локальные данные и домашний обмен.

## Для разработчика

Node.js 22.13+ (проверено на 24), без npm-зависимостей:

```sh
cd recognizer
npm test
```

Официальная модель и схема: [Gemma 3 12B IT](https://developers.cloudflare.com/workers-ai/models/gemma-3-12b-it/). Используется `AI.run`, multimodal `messages`, data URL изображений и `guided_json`. Два снимка максимум; входящий JSON ≤ 3 MB; клиент уменьшает каждый JPEG до ≤ 1600 px / 900 KB. Семейный токен — HMAC-SHA256 с отдельным контекстом `photo-v1:room`; на сервере хранится только его SHA-256. Это не ключ API аккаунта и не ключ шифрования журнала.
