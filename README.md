# Сроки · общий холодильник

**[Скачать APK для Android 12+](https://github.com/firesemen/goods_page/raw/refs/heads/fridge-days/downloads/fridge-days-0.3.0-debug.apk)** · **[Скачать исходники](https://github.com/firesemen/goods_page/raw/refs/heads/fridge-days/downloads/fridge-days-source.zip)**

Android 12+ приложение для семейного холодильника. Данные хранятся на телефонах; без интернета доступны список, изменения, фото и локальные уведомления. Есть обмен рядом и подключаемый зашифрованный облачный транспорт. Google-аккаунт и Google Play Services не нужны.

Этот продукт находится в отдельной ветке `fridge-days` репозитория `firesemen/goods_page`.

## Что реализовано

- Одна карточка на упаковку: название, количество, единица из списка, дата, одно фото.
- Ввод «годен до» или расчёт по дате изготовления и дням хранения.
- «Открыто»: min(срок упаковки, дата открытия + выбранное количество дней), с отменой. От 1 до 365 дней, по умолчанию 3.
- Следующие 2 дня — пометка об окончании официального срока; затем просроченная карточка сохраняется до удаления.
- Списание ползунком с точным вводом остатка, дробные литры/килограммы, фильтры и сортировка по ближайшему сроку.
- Приглашение семьи по ссылке и QR, сканирование камерой.
- Шифрованный двусторонний обмен в общей Wi-Fi-сети при открытых приложениях.
- Ежедневная локальная сводка около 09:00; час и часовой пояс настраиваются.
- Фото из галереи/камеры, уменьшение до 800 px / 170 КБ JPEG.
- Зашифрованная резервная копия с паролем, включая фото и ключ семьи.
- Необязательный облачный ретранслятор: реализация API и фоновой синхронизации включена, экземпляр не развёрнут.

Исследование аналогов, обоснование дополнений и источники: [docs/RESEARCH.md](docs/RESEARCH.md). Детали согласования, шифрования и ограничений: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Обновление до 0.3.0

Добавлено гибридное заполнение карточки по фото: локальный русский/английский OCR без интернета и отдельная облачная кнопка через ваш Worker. Можно использовать фото упаковки и второй снимок срока крупным планом. Распознавание предлагает черновик с фрагментами надписей; каждую дату нужно подтвердить вручную. Перенос в форму ещё не сохраняет карточку.

Локальные словари уже в APK; Google Play Services не нужны. Картинка карточки по-прежнему компактная, исходные снимки обрабатываются отдельно в приватном кэше. APK выросла примерно до 32 MiB из-за движка, словарей и четырёх архитектур процессора.

**[Установить Worker через сайт Cloudflare](recognizer/README.md)** — пошагово, без командной строки и API-токена. Облачная обработка заработает после вашей установки; из среды ничего в Cloudflare не публиковалось. Адрес распознавания задаётся отдельно на каждом телефоне в **шестерёнке → Распознавание по фото**.

Сохранение прокрутки после действий с карточками и возврата из редактора остаётся в этой версии. Подробности сценария и ограничений OCR: [docs/PHOTO_PLAN.md](docs/PHOTO_PLAN.md).

## Совместимость

Установите новую APK **на оба телефона поверх текущей версии**, без удаления приложения. Пакет и подпись прежние; список, фотографии и приглашение семьи сохраняются. Начиная с версии 0.2 используются новое поле срока после открытия и дробные количества; версия 0.1 не умеет принимать такие изменения, поэтому для обмена нужны две обновлённые установки.

Все изменения интерфейса описаны в [CHANGELOG.md](CHANGELOG.md). Настройки открываются шестерёнкой справа сверху; статус сохранения и обмена находится там же.

## Установка APK на два телефона

1. Установить один и тот же `app/build/outputs/apk/debug/app-debug.apk`. Это подписанная debug-сборка для личного тестирования, не магазинный релиз.
2. На первом телефоне добавить продукты. В разделе **Семья → Пригласить по QR / ссылке** показать приглашение.
3. На втором телефоне до добавления своих продуктов открыть **Семья → Сканировать приглашение** или вставить ссылку.
4. Подключить телефоны к одному домашнему Wi-Fi и держать оба приложения открытыми. При необходимости нажать **Повторить обмен рядом**. Пока приложения открыты, проверка выполняется каждые 20 секунд.
5. В **Настройках** разрешить уведомления и проверить сводку. Пояс по умолчанию — Москва; на обоих телефонах он должен совпадать.

Не публикуйте QR/ссылку: они содержат ключ семьи. Смена подключённой семьи с непустым журналом в текущем интерфейсе блокируется, чтобы не потерять локальные данные. Модель разделена по семьям и холодильникам, но переключатель нескольких семей ещё не включён.

Без облака обмен работает только при встрече в общей сети с разрешёнными mDNS и соединениями между клиентами. Гостевые Wi-Fi часто изолируют устройства. Список доступен постоянно, но удалённые изменения появятся после следующего успешного обмена.

## Сборка на своём компьютере

Нужны Android Studio, JDK 17 или 21 и Android SDK Platform 35 / Build Tools 35.0.0. Android Studio может установить SDK при синхронизации Gradle. Путь SDK задаётся стандартным `local.properties` (`sdk.dir=...`) или `ANDROID_HOME`.

Linux/macOS:

```sh
./gradlew :core:verifyCore :app:assembleDebug :app:lintDebug
```

Windows PowerShell:

```powershell
.\gradlew.bat :core:verifyCore :app:assembleDebug :app:lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Gradle Wrapper 8.11.1 зафиксирован вместе с SHA-256 дистрибутива; Android Gradle Plugin 8.9.2, ZXing Core 3.5.3. Готовый нативный OCR AAR и словари входят в исходники; NDK для обычной сборки приложения не нужен. Их происхождение, хеши, лицензии и пересборка: [app/libs/README.md](app/libs/README.md).

Debug-подпись создаётся на компьютере сборки. Для обновления уже установленного APK нужна та же подпись: сохраняйте ключ либо перед переходом к собственной сборке сделайте зашифрованную копию и восстановите её после переустановки. Не меняйте подпись установленного приложения без копии данных.

## Проверки

Ядро без Android SDK:

```sh
bash scripts/test-core.sh
```

Облачный протокол на настоящем SQLite, Node.js 22.13+ (выполнено на Node 24):

```sh
cd relay
npm test
```

Контракт облачного распознавания (AI подменён в тесте, счётчик на настоящем SQLite):

```sh
cd recognizer
npm test
```

Настоящий офлайн OCR на Android, два синтетических печатных снимка и подтверждение черновика:

```sh
./gradlew -Pfridge.testRunner=ru.fridgedays.app.PhotoInstrumentation :app:connectedDebugAndroidTest
```

На подключённом Android-устройстве/эмуляторе:

```sh
./gradlew :app:connectedDebugAndroidTest
```

Проверка интерфейса 0.2:

```sh
./gradlew -Pfridge.testRunner=ru.fridgedays.app.UiInstrumentation :app:connectedDebugAndroidTest
```

Дополнительная проверка Wi-Fi использует два независимых журнала в Android-эмуляторе, настоящее обнаружение NSD и двусторонние сокеты приложения:

```sh
./gradlew -Pfridge.testRunner=ru.fridgedays.app.WifiInstrumentation :app:connectedDebugAndroidTest
```

Проверяется обнаружение участников, обмен более чем одной порцией событий и данными фото, повторное подключение после автономного расхода, удаление и повторная доставка без дубликатов. Это не заменяет проверку двух физических телефонов через домашний роутер.

Инструментальный smoke-runner проверяет Android Keystore, шифрованные операции в SQLite, правило дат, слияние автономного расхода, отбрасывание повреждённых данных, резервную копию, реальную форму добавления, фото через MediaStore/ImageDecoder, отображение карточки, локальную сводку и настоящий LAN-сокет. Тестовые карточки помечаются удалёнными в конце. Камера, mDNS между двумя физическими телефонами, уведомления после перезагрузки и энергопотребление требуют отдельного испытания по [чек-листу](docs/PHONE_CHECKLIST.md).

## Подключение обмена через интернет

Собственный постоянно работающий сервер покупать не требуется. Дополнительный пример использует бесплатный тариф Cloudflare Workers + D1, который имеет лимиты и зависит от доступности провайдера в РФ. Для первого знакомства можно пользоваться только обменом рядом.

Инструкции развёртывания: [relay/README.md](relay/README.md). Нужен аккаунт провайдера; конфигурация и сервер автоматически не публиковались. В приложении нет скрытого публичного сервера или ключа чужого аккаунта.

## Что ещё не входит в релиз

Семейные шаблоны распознавания, поиск товара по штрихкоду, рецепты, морозилка, шкаф, переключение нескольких семей, индивидуальный отзыв участника и ротация ключей. Облако вне домашней сети будет работать после отдельного развёртывания и проверки ретранслятора.
